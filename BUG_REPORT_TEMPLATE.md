# Bug report template — 13-mod staging multiplayer test

Copy, fill in, and send to the server host together with a screenshot or video. This is a **test world**: progress may be discarded.

```
Player:
Time:
Number of players online:
Location:
Mod/system being tested:
What happened:
Expected behavior:
Can reproduce:
Screenshot/video:
Server restart required:
Additional notes:
```

Host notes when filing a report into the project:
- Record the server-log time window and the session batch id (for example `mp13-session-1`).
- Do not paste private addresses, passwords or Radmin network credentials into the report.
- If a report suggests save/persistence damage, stop the test, keep the server log, and take or verify a backup before any further boot.
